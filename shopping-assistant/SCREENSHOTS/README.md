## שחזור הצילומים

```bash
cd shopping-assistant
npm install
npm run build
npm run preview -- --port 4173 --strictPort &

# התקנת playwright-core ללא הוספה ל-package.json
npm install --no-save playwright-core

# הרצת סקריפט הצילום (ראו PROJECT_HANDOFF.md לפרטים)
node shots.mjs
```

**הערה על הסביבה:** בסביבת הפיתוח המרוחקת, Chromium מותקן מראש ב‑`/opt/pw-browsers/chromium`
ויש להעביר אותו כ‑`executablePath`. אין להריץ `playwright install`.

## עדכון הצילומים

יש לצלם מחדש **בכל שינוי ויזואלי משמעותי**:
* שינוי במערכת העיצוב (צבעים, גופן, ריווח)
* הוספת מסך חדש
* שינוי מבני בפריסה
* תיקון באג ויזואלי (כדי לתעד את התיקון)

**שמרו על מוסכמת השמות:** `NN-screen-name[-dark|-mobile].png`
המספור מבטיח סדר תצוגה עקבי בכל מערכת קבצים.
