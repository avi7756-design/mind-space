## נספח: GitHub Action לפריסה אוטומטית

זו המשימה 1.1.7 — מחליפה את התהליך הידני המתואר ב‑`PROJECT_HANDOFF.md` §9.

```yaml
# .github/workflows/deploy-shopping.yml
name: Build & Deploy Shopping Assistant

on:
  push:
    branches: [claude/shopping-assistant-app-139m55]
    paths: ['shopping-assistant/**']
  workflow_dispatch:

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: shopping-assistant/package-lock.json

      - name: Install
        working-directory: shopping-assistant
        run: npm ci

      - name: Typecheck & Build
        working-directory: shopping-assistant
        run: npm run build

      # (אחרי v1.1 להוסיף:)
      # - name: Test
      #   working-directory: shopping-assistant
      #   run: npm run test

      - name: Deploy to main/shopping
        run: |
          git config user.name  "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          cp -r shopping-assistant/dist /tmp/shopping-dist
          git fetch origin main
          git checkout main
          rm -rf shopping
          mkdir -p shopping
          cp -r /tmp/shopping-dist/. shopping/
          git add shopping
          git diff --staged --quiet || git commit -m "פריסה אוטומטית: עוזר הקניות ($GITHUB_SHA)"
          git push origin main
```

## עקרונות תעדוף

1. **יציבות לפני יכולות.** v1.1 לפני הכול — בלי בדיקות כל שינוי הוא הימור.
2. **חוויה לפני עומק.** משתמש שלא מצליח להשתמש במובייל לא יגיע לפיצ׳רים המתקדמים.
3. **נתונים אמיתיים לפני AI.** AI על נתוני דמו הוא תרגיל, לא מוצר.
4. **מבחן ההחלטה.** כל פיצ׳ר עובר: *האם זה עוזר להחליט?*
5. **אבטחה לא נדחית.** כל משימת אבטחה נכנסת לגרסה שבה הסיכון נוצר, לא אחריה.
