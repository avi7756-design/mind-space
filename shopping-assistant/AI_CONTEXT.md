**מה זה:** אפליקציית ווב בעברית שעוזרת להחליט **איפה הכי כדאי לקנות מוצר**,
על בסיס עלות כוללת (ולא מחיר מדבקה) + אמינות ספק + משלוח + אחריות + החזרות.

**איפה זה:**

* ריפו: `avi7756-design/mind-space`
* חי: https://avi7756-design.github.io/mind-space/shopping/

**מה המחסנית:** React 18 + TypeScript 5 (strict) + Vite 5 + Tailwind 3 + Zustand 4 + Recharts 2

**מה המצב:** Frontend מלא, מלוטש ופרוס. **Backend — אין. בסיס נתונים — אין.
אימות — אין. AI — אין.** הכול רץ על נתוני דמו.

**מה הכי חשוב להבין:** יש **נקודת אינטגרציה אחת** בכל המערכת —

## חלק ה׳ — מלכודות ידועות

### מלכודת 1: "הוספתי ספק ל‑seed והוא לא מופיע"

**הסיבה:** `zustand/persist` שמר את מאגר הספקים ב‑`localStorage`. הוא לא ייקרא
מחדש מה‑seed.

**פתרון זמני:** `localStorage.removeItem('shopping-assistant-store')` בקונסולה.
**פתרון אמיתי:** להוסיף `migrate` (ראו באג B2).

### מלכודת 2: "שיניתי את המשקולות והציונים לא השתנו"

**זה לא באג.** המשקולות נשמרות רק בלחיצה על "שמירת הגדרות", והכפתור **חסום**
כשהסכום ≠ 100%.

### מלכודת 3: "הציון של הצעה בודדת הוא 93 — למה?"

כשיש הצעה אחת, `min === max` בכל הממדים היחסיים, ולכן כולם מקבלים 100.
זה **באג ידוע (B14)** שטרם תוקן.

### מלכודת 4: "האמינות לא מנורמלת כמו שאר הממדים"

**זה מכוון.** אמינות היא תכונה מוחלטת של הספק, לא יחסית להשוואה. ספק עם 64
מקבל 64 גם אם הוא הכי אמין בתוצאות.

### מלכודת 5: "חיפשתי שוב את אותו מוצר ולא קרה כלום"

**באג B5.** ה‑effect משווה `urlQuery !== searched`. חיפוש חוזר של אותו טקסט
לא מפעיל כלום.

### מלכודת 6: "ההתראות מסומנות 'נשלחה' אבל לא קיבלתי כלום"

**אין קוד ששולח.** `'sent'` משמעו "היה ערוץ פעיל". דורש Backend.

### מלכודת 7: "יש שני מקומות עם שדה חיפוש"

`Topbar` (גלובלי, מנווט ל‑`/search?q=`) ו‑`SearchPage` (מקומי). הם מסונכרנים
דרך ה‑URL. זה מכוון אך מבלבל (UX U5).

### מלכודת 8: "`ACTIVITY_META` מיובא מעמוד לעמוד"

`DashboardPage` מייבא מ‑`ActivityPage`. זו הפרת שכבות ידועה (B6).
אם אתה נוגע — העבר ל‑`src/constants/activity.ts`.

## חלק ו׳ — הקשר AI ספציפי

### מה **אין** במערכת

**אפס רכיבי AI.** אין LLM, אין embeddings, אין vector DB, אין OCR, אין Vision.

"חיפוש בשפה טבעית" הוא שם שיווקי לפונקציה הזו:

```ts
export function findCatalogEntry(query: string) {
  const q = query.toLowerCase();
  return CATALOG.find(entry => entry.keywords.some(k => q.includes(k)));
}
```

`String.includes` על 5 ערכים. **זה הכול.**

### שתי ההזדמנויות בעלות הערך הגבוה ביותר

**1. פירוק שאילתה (קל, ערך מיידי)**

המשתמש כותב "אוזניות אלחוטיות עם סינון רעשים עד 1,500 ש״ח". כרגע כל המידע
המובנה הולך לאיבוד. קריאת LLM אחת פותרת:

```ts
interface ParsedQuery {
  category: string;
  brand?: string;
  maxBudget?: number;          // ← הופך למסנן
  requiredFeatures: string[];   // ← הופך לניקוד
}
```

**מימוש:** בשרת בלבד. נקודת החיבור: לפני `searchOffers`, לא בתוכו.

**2. התאמת מוצרים בין ספקים (קשה, קריטי)**

`Sony WH-1000XM5 Black` מול `אוזניות סוני XM5 שחור` מול `WH1000XM5/B`.

**בלי לפתור את זה, אין השוואת מחירים אמיתית — רק רשימת מוצרים שונים.**
זו החסימה האמיתית במעבר מדמו למוצר. פתרון: embeddings + דמיון קוסינוס + אימות LLM.

### כללי ברזל ליישום AI כאן

| # | הכלל |
|---|---|
| 1 | **AI רץ בשרת בלבד.** מפתח API בלקוח = דלף מיידי |
| 2 | **כל יכולת AI חייבת fallback.** LLM נכשל → המערכת חוזרת להתנהגות הנוכחית |
| 3 | **לא להציג חיזוי כעובדה.** "צפוי לרדת" ≠ "ירד" |
| 4 | **לסמן תוכן שנוצר ב‑AI** |
| 5 | **`scoring.ts` נשאר דטרמיניסטי.** AI יכול להזין אותו — לא להחליף אותו |

**נימוק לכלל 5:** הערך של המוצר הוא ש**המשתמש מבין למה ההמלצה כזו**.
"מודל החליט" הורס את זה.

## חלק ז׳ — סגנון קוד שחייבים לשמר

```tsx
// ✅ כך כותבים רכיב
interface Props {
  title: string;
  onSelect?: (id: string) => void;
}

export default function MyComponent({ title, onSelect }: Props) {
  const items = useAppStore(s => s.items);        // סלקטור ממוקד
  const sorted = useMemo(() => sortItems(items), [items]);
  return <div className="card p-5">{title}</div>;
}
```

```tsx
// ❌ לא כך
export const MyComponent: React.FC<{title: string}> = ({title}) => {
  const store = useAppStore();                     // כל ה-store
  return <div style={{padding: 20}}>{title}</div>; // inline styles
}
```

**כללים:**
* `export default function` — לא `React.FC`, לא arrow
* `interface Props` מעל הרכיב, לא inline
* Tailwind בלבד — אין `style={{}}`
* סלקטור ממוקד — לא `useAppStore()` ריק
* וריאנטים כ‑`Record<Tone, string>` — לא שרשור מחרוזות
* **הערות רק כשהן מסבירות *למה*** — הקוד מסביר את *מה*
* טקסט למשתמש בעברית, שמות משתנים באנגלית
* מספרים דרך `format.ts` בלבד
